# Expanded coffee menu

The menu now contains eleven drinks. Six additions: Flat White, Caramel Latte, Iced Latte, Cold Brew, White Chocolate Mocha, and Cortado. Existing IDs and prices are preserved. New menu prices and ratings are demonstration data.

Search, category filtering, product details, favorites, and cart use the shared catalog. Latte and Mocha include their variants; Iced includes Iced Latte and Cold Brew. Milk and iced flags are explicit per drink. Backend remains the existing in-memory preview.
